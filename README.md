# Linux и Python за 4 дня — тренажёр под собеседование QA

Интерактивный курс под конкретную вакансию: **QA-инженер тестирования функций сервисов ядра мобильной сети (5G)**.
Закрывает то, чему работодатель учить не будет: Linux-консоль, Python руками, requests + pytest.
Теорию 4G/5G сюда намеренно не включал — по вакансии ей обучает ментор.

Работает офлайн, в одном браузере, без интернета, без Python на машине и без установки чего-либо.

## Запуск

Двойной клик по `Запустить курс.cmd` — откроется браузер на `http://localhost:8801`.

Либо вручную:

```bash
python -m http.server 8801 --directory C:/Users/Toni/Desktop/qa-course
```

Можно и просто открыть `index.html` двойным кликом — всё работает и по `file://`.

## Чем это отличается от обычного курса

**Всё выполняется по-настоящему.** В проекте два собственных движка:

- `js/py/` — интерпретатор Python на JavaScript: лексер с отступами, парсер, исполнение, встроенные функции, модули `json`, `re`, `os`, `csv`, `math`, `time`, `random`, `subprocess`, `requests` и `pytest` с настоящим раннером (фикстуры, `parametrize`, `raises`, `approx`, отчёт в формате pytest);
- `js/shell/` — симулятор bash поверх виртуального стенда: около 50 команд, пайпы, редиректы, `&&`, кавычки, история, Tab-дополнение.

**Стенд общий для консоли и кода.** Учебный узел ядра: файловая система, службы systemd, сокеты, DNS, фаервол, диск и HTTP-API регистрации абонентов. Из консоли вы его чините, из Python — тестируете. `subprocess.run(["systemctl", "is-active", ...])` в уроке дня 3 реально дёргает тот же стенд, что и консоль дня 2.

**Сценарии поломок.** Квесты запускаются со сломанным состоянием: опечатка в конфиге, привязка к 127.0.0.1, упавшая база, забитый диск, занятый порт, сломанный DNS. Проверка задания смотрит не на текст ответа, а на **фактическое состояние стенда**: служба поднята, конфиг исправлен, сессия создана.

## Проверка целостности

```bash
node test/run.js
```

Прогоняет эталонное решение каждого урока через его же проверки — курс не может «протухнуть» незаметно.

## Структура

```
index.html                 интерфейс
css/style.css              оформление (тёмная/светлая тема)
js/py/                     интерпретатор Python: lexer, parser, interp, builtins, stdlib
js/shell/                  стенд (stand.js) и симулятор bash (shell.js)
js/engine.js               запуск кода и проверка заданий (без DOM — используется и в тестах)
js/ui/                     терминал и редактор
js/content/                уроки по дням, шпаргалка, вопросы экзамена
js/app.js                  сборка, прогресс, XP, режим собеседования
test/run.js                автотест курса
```

Прогресс, XP и написанный код хранятся в localStorage браузера. Кнопка ⟲ в шапке сбрасывает всё.

## Как проходить

По уроку за раз, подряд. На день — примерно 2–3 часа плотной работы.
Не открывайте подсказку раньше, чем сделали две попытки: ценность тренажёра именно в том, что вы вспоминаете команду сами.

После четвёртого дня: пройдите режим 🎯 несколько раз подряд. 8 из 10 без подсказок — можно идти на техническое собеседование по этому блоку.
