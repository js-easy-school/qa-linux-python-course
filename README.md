# QA Automation 5G Core — практический курс

Интерактивный тренажёр под вакансию QA automation функций 5G Core. Курс не обещает
«стать senior за неделю»: он доводит до проверяемого junior/junior+ уровня,
помогает защитить портфолио-проект и показывает, какие темы ещё не закреплены.

Работает офлайн в браузере. Прогресс, код, ошибки и интервальные повторения
хранятся в localStorage.

## Запуск

Двойной клик по `Запустить курс.cmd` или:

```bash
python -m http.server 8801 --directory C:/Users/Toni/Desktop/qa-course
```

Откройте `http://localhost:8801`.

## Программа

59 проверяемых уроков и 55 вопросов режима собеседования.

| День | Практика | Уроков |
|---|---|---:|
| 1 | Linux: файлы, логи, grep, пайпы, поля, find, evidence | 10 |
| 2 | Процессы, systemd, sockets, сеть, curl и инциденты | 10 |
| 3 | Python для диагностических скриптов | 10 |
| 4 | requests, pytest, fixtures, negative и dependency failure | 9 |
| 5 | Docker Compose, inspect, multi-service logs и CI gates | 5 |
| 6 | NRF/SBI, N2/NGAP/SCTP, PFCP, GTP-U, registration и PDU | 5 |
| 7 | Subscriber data, BDD, pytest markers, packet capture, bad-key | 5 |
| 8 | Четыре 5G-инцидента и самостоятельная приёмка стенда | 5 |

Для каждого урока первых четырёх дней добавлен педагогический блок:

- зачем тема нужна QA 5G;
- что именно наблюдать в выводе;
- типичная ошибка начинающего;
- как объяснить решение на собеседовании.

## Живая визуализация и словарь

- В каждом практическом уроке схема заранее показывает предполагаемый путь команды, а после Enter — фактический успешный или ошибочный маршрут.
- Для Linux отображаются терминал, shell, файлы, процессы, systemd, сокеты и сеть; для Python — выполнение, данные, проверки и отчёт; для 5G — UE, gNB, AMF, AUSF/UDM, NRF, SMF, UPF и MongoDB.
- Цветные индикаторы отражают состояние учебного стенда, а кнопка `Повторить` заново проигрывает последний маршрут.
- Кнопка `Отдельно` переносит схему в плавающее изменяемое окно; его можно растянуть, свернуть, вернуть в курс или развернуть на весь экран.
- Команды и технические сокращения прямо в обычном тексте (`SSH`, `API`, `SCTP`, `NRF`, `PDU`, `IMSI` и другие) снабжены короткими подсказками: наведите мышь или переведите фокус с клавиатуры; на телефоне нажмите на термин.

## Умное повторение

Кнопка `↻` открывает очередь интервального повторения.

- первая успешная попытка означает «пройдено», но не «закреплено»;
- повтор начинается через 10 минут, затем интервалы растут до 1, 3, 7 и 14 дней;
- ошибка снижает прочность навыка и возвращает тему в ближнюю очередь;
- в review mode теория, подсказки и решение закрыты: сначала воспроизведение по памяти;
- «закреплено» требует минимум двух успешных подходов.

Ориентир готовности к собеседованию: не менее 80% закреплённых уроков,
финальная рабочая смена без решения и три экзамена подряд не ниже 8/10.

## Движки тренажёра

- `js/py/` — учебный Python runtime с requests/pytest;
- `js/shell/` — bash-подобная консоль, virtual filesystem и 5G lab state;
- Docker/Compose simulation — ps, logs, inspect, stats, exec, config;
- 5G scenarios — missing UDM, NGAP destination mismatch, MAC failure,
  missing TUN/PFCP и healthy end-to-end flow.

Симуляция нужна для обучения без Linux. Реальный portfolio stand находится в
репозитории `open5gs-test-stand` и требует Linux kernel с TUN и SCTP.

## Проверка целостности

```bash
node test/run.js
```

Тест выполняет эталонное решение каждого из 59 уроков, проверяет уникальные id,
mentor notes и все regex режима собеседования.

## Как проходить

1. Прочитайте теорию и комментарий наставника.
2. Предскажите вывод команды до запуска.
3. Выполните задание без подсказки.
4. Объясните результат вслух по схеме «проверка → факт → вывод → следующий шаг».
5. Вернитесь к теме через очередь ↻, пока она не станет закреплённой.
6. В конце каждого дня оформите короткий incident note или test report.

Верхняя граница зарплатной вилки обосновывается не фактом прохождения курса, а
способностью самостоятельно провести triage, написать тест, защитить RCA и
показать воспроизводимый GitHub-проект.
